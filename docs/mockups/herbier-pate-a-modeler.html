État local

state garde une valeur qui vous appartient, en mémoire, sous forme de signal — avec ses méthodes et ses valeurs dérivées collées dessus.

✔ À utiliser pourun brouillon de formulaireune sélectionun compteur

Le cas courant

On donne un nom, une valeur de départ, puis on façonne les méthodes dans le contexte d’insertion.

counter.ts
import { craftComputed, state, craftUse } from '@craft-ts/core';

const counter = yield* state('counter', 0, ({ state, update, set }) => ({
  increment: () => update((value) => value + 1),
  reset: () => set(0),
  isEven: craftUse(craftComputed('isEven', function* () {
    return (yield* state()) % 2 === 0;
  })),
}));

yield* counter(); // 0
yield* counter.increment();
yield* counter.isEven(); // false
Nouveau devant la forme ?

Le nom, la déstructuration, le pilote yield* et la règle d’usage unique sont les mêmes pour les cinq primitives.
