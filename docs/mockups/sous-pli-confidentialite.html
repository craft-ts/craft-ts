Principes

Quatre règles que le design applique à votre place

Voilé par défaut

Une valeur voilée n'est pas dans le DOM. Un flou CSS ne protège rien, une barre vide oui.

Lever demande un geste

Un clic pour Confidentiel, un appui maintenu pour Secret. Le geste est proportionné au risque.

Chaque lecture se voit

Qui a levé quoi, et quand, s'écrit dans un journal que la personne concernée peut lire.

Le niveau se voit sans lire

Densité du motif, épaisseur du cadre et couleur disent la même chose. Aucun des trois n'est seul.

Règles

Ce que le système impose, ce qu'il refuse

Impose

  • Une valeur voilée est absente du DOM.
  • Une durée de levée bornée par le niveau.
  • Une ligne de journal pour chaque levée.
  • Un niveau lisible sans la couleur : cadre et motif le répètent.

Refuse

  • Le flou comme seule protection d'une donnée.
  • Copier une valeur tant qu'elle est voilée.
  • Une valeur sensible dans un titre, une URL ou un toast.
  • Un niveau signalé par la couleur seule.
