Le modèle

Quatre temps, dans cet ordre.

Chaque primitive suit le même chemin : on la déclare, on la lit, on en dérive d’autres, et le compilateur vérifie le tout.

1

Déclarer

Un nom, une configuration, des insertions.

state('counter', 0)
2

Yielder

On lit la valeur là où l’on en a besoin.

yield* counter()
3

Dériver

Le calcul suit, et seulement lui.

craftComputed('isEven')
4

Compiler

Les erreurs se voient avant l’exécution.

tsc --noEmit
Points forts

Ce qui change au quotidien.

Les agents pilotent l’onglet ouvert

En développement, l’appli publie ses contrôles nommés. Un agent remplit, clique et inspecte, sans second navigateur.

Réactivité fine

Un signal lu dans une liaison n’invalide que ce texte, cette propriété, cette classe. Le reste ne bouge pas.

Une API pour tous les états

state, query, mutation, queryParams, asyncProcess : même forme, apprise une fois.

Très composable

L’état se compose avec des insertions, les composants avec des directives, le tout via .pipe(…).

Des services, pas des classes

Une fabrique avec un nom et une portée. On la yield* où l’on veut : pas d’@Injectable.

Composants sans sélecteur

Ni balise ni décorateur : le composant est une fonction qui rend un gabarit.

État local

state garde une valeur qui vous appartient, en mémoire, sous forme de signal — avec ses méthodes et ses valeurs dérivées collées dessus.

À utiliser pourun brouillon de formulaireune sélectionun compteur

Le cas courant

On donne un nom, une valeur de départ, puis on définit les méthodes dans le contexte d’insertion.

counter.ts
import { craftComputed, state, craftUse } from '@craft-ts/core';

const counter = yield* state('counter', 0, ({ state, update, set }) => ({
  increment: () => update((value) => value + 1),
  reset: () => set(0),
  isEven: craftUse(craftComputed('isEven', function* () {
    return (yield* state()) % 2 === 0;
  })),
}));

yield* counter(); // 0
yield* counter.increment();
yield* counter.isEven(); // false
Astuce

Le nom, la déstructuration, le pilote yield* et la règle d’usage unique sont les mêmes pour les cinq primitives.

Fondations

Six pâtes, deux encres.

Des teintes terreuses et désaturées, toutes dérivées du vert d’épicéa d’Herbier. La matière reste discrète : le travail se fait dans la couleur. Les rapports de contraste ci-dessous sont calculés en direct pour le mode affiché.

Règles d’usage

  • Une seule teinte d’action par écran : l’épicéa. L’ocre est un accent, jamais un fond de texte long.
  • La brique signale l’attention ou le danger ; l’ardoise, l’information et la navigation secondaire.
  • Le texte long vit sur l’os ou la sauge claire, jamais sur une teinte saturée.
  • Le grain reste sous 15 % en jour et 20 % en nuit : il donne de la chaleur sans bruit visuel.
